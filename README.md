# EventSpace and Services

**EventSpace and Services** is a web-based event management platform with three roles: **Admin, Vendor, and User**. Vendors can register and offer event-related services, which are reviewed and approved or rejected by the Admin. Users can explore available services, add them to their wishlist, and book services for their events.

The booking process includes **vendor approval of booking requests followed by a dummy payment process**, with the Admin receiving a commission as platform revenue from completed payments.

### Tech Stack

* **Frontend:** HTML, CSS, JavaScript, Bootstrap
* **Backend:** PHP
* **Database:** MySQL
* **Tools:** XAMPP, VS Code

### Key Features

* Admin, Vendor & User Roles
* Vendor Registration & Admin Approval
* Service & Package Management
* Vendor Portfolio
* Wishlist
* Event Service Booking
* Vendor Booking Approval
* Dummy Payment & Admin Commission
* Ratings & Reviews
* Admin Dashboard
